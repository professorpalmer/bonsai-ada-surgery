bonsai-ada-surgery - built-in web chat page - third-party software
================================================================================

The engine (llama-server) holds a web chat page. The page is the web UI of llama.cpp
(tools/ui in the engine source, commit 21fd9beda; MIT License, the ggml authors).
The build compiles the page and the npm packages that it uses into these files, which
llama-server-impl.dll (Windows) contains:
  _app/immutable/bundle.2_bTo9Z-.js, _app/immutable/assets/bundle.CsYLz1sd.css,
  sw.js, workbox-b3c04f83.js, index.html, manifest.webmanifest and icons.

This file lists the third-party software in those files, with the licence and the
copyright and licence text of each item. The list comes from the module list of the
build (package-lock.json of the engine source), not from package.json alone. Packages
that are only build or test tools and put no code into the output are not in the list.

The list was made from the UI source with this sha256 (lockfile, configs, scripts, src):
UI source fingerprint: 9de51537a3d667b36924849d82c7cf6d0622f9eb18ddc190bb6f660bc1bec4c7

Items: 202. Licences: MIT (165), ISC (22), BSD-3-Clause (7), Apache-2.0 (6), (MPL-2.0 OR Apache-2.0) (1), Unlicense (1).
