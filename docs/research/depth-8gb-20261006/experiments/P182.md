## Question

Does the window-32k candidate, chosen on the prose set, hold on the needle set and the code set? And does keeping the
first 4 full-attention layers dense help prose at 16k?

## Plan and gate

Script header: "T5 candidate = window 32k / sink 1k / tail 1k, run skip, bin-t5r3; P178 R-4 prose 9/24 at 1.77x: confirm

## Verdict

Reported. T5 window 32k / sink 1k / tail 1k (no dense layers) gets 52/72 on the three 245k-class sets against 54/72 for
the full read, at 801-814 s instead of 1,418-1,452 s (~1.77-1.78x), about one item per set lost (n24 +1, code -1, prose
-2). Prose 16k + the first 4 dense layers (6/24) is worse than the even 4 (9/24). The 2060 proposes window 32k as an
opt-in fast cold read (#138 21:54:09Z, events E85).
