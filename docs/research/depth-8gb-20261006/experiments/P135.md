## Question

On the release candidate with the opt-in launcher, is BONSAI_SPARSE=1 at least 1.8x dense at 160k and 245k on the
2060, and does it stay inside VRAM?

## Why

R06 (the 4070's release gates for bundle-20261014) needs the 2060's deep speed and the 245k trace minimum. P124 had
shown 43 MiB minimum free at 245k on the older build: the launcher headroom was in question.

## Plan and gate

Script header: "Gates (declared here, before the run; R06 items): op tests 0 FAIL; sparse >= 1.8x dense at 160k and
245k; 0 one-token; trace min free >= 60 MiB in both arms (the 4070 is checking the launcher headroom: report the
minimum either way)."

Amendment before the sparse arm (#49 3035572, 13:16Z): "160k gate for opt-in now >= 1.5x (245k stays 1.8x)".

## Method

Build 4de618549 for 75-real. test-backend-ops FLASH_ATTN_EXT and GATED_DELTA_NET. Two arms, one server each, quick_tps
160000 then 245000 (cold 160k, then extend to 245k), 10 s free-VRAM trace, sparse_mask line count.
