## Question

Below 128k, does the full 262k window cost decode speed against a 131k window?

## Why

Cary: "the card says set 131k". If the full window costs nothing up to 128k, the card and the docs can say so and not
advise a shorter window.

## Plan and gate

Script header: "BONSAI_CTX=131072 vs the default 262144, alternated x2, one server each, extend sweep 4k / 64k / 96k /
128k. Rule (declared before the run): if 262k is within 2 % of 131k at every depth, the card and docs can say "the full
window costs nothing up to 128k; only filling it is slow". Otherwise report the gap per depth and the two VRAM lines."

## Method

(Planned.) Four servers: c131_r1, c262_r1, c131_r2, c262_r2; quick_tps 4000 -> 64000 -> 96000 -> 128000; the
"window" and "kv" launcher lines saved per arm.
