## Question

Does the published bundle-20261016 zip run the 8 GB defaults (q3_0, automatic sparse) on the 2060 with the speed of
P146's auto arm?

## Why

The card's release receipt. bundle-20261016 ships patch 0059 (sparse on by default for 8 GB: late reserve +
self-timing engage) with q3_0 K/V.

## Plan and gate

Script header: "Gates (declared here, before the run): sha256 match; zip launcher 0 control bytes; --version commit
ab94810051; FLASH_ATTN_EXT / GET_ROWS / SET_ROWS 0 FAIL; the default launch prints "window 262144 / q3_0", a line of
78k-82k and "sparse host-tail reads: auto"; one-server sweep 4k / 64k / 128k / 160k / 245k within 3 % of P146 auto (64k
41.0, 128k 22.8, 160k 16.0, 245k 9.8) and P130 (4k 53.6); 0 one-token; trace min free >= 60 MiB."
