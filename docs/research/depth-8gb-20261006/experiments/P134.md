## Question

Did the new NVIDIA driver 610.88 (installed by Windows Update at 02:29-02:30) change decode past the VRAM line?

## Why

Windows Update installed "NVIDIA Display Driver Update (32.0.16.1088)" and restarted the PC during P124 (events E38).
Every later run is on 610.88. A cross-driver comparison is not valid without a same-binary baseline.

## Plan and gate

Script header: "Reading (declared before the run): the driver effect = these numbers vs P126b (591.86: 1013 means 35.65
/ 25.95 / 17.1; 1011 36.0 / 26.0 / 16.85). Gate for continuing the queue: op tests pass and 0 one-token; report the
driver delta."

## Method

Op tests (ADD, RMS_NORM, FLASH_ATTN_EXT, GATED_DELTA_NET). Then the P126b arms: 1011, 1013, 1011, 1013, one server
each, quick_tps 64000 -> 96000 -> 128000.

## Toolbox (for the next model)

- Method: after any driver change, rerun one known same-session A/B on the same binaries before new comparisons.
- Pitfall: on this card the decode past the line follows the VRAM line (which moves with idle VRAM after a reboot);
  log the line per arm before reading a driver or release delta.
