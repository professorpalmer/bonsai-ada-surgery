## Question

On Turing, does packing 2 Q heads per column group in the prefill MMA attention kernel (GQA ratio 8) keep the answers
exact and cut the cold prefill time?

## Why

P151: attention is ~65 % of a cold 245k prefill. The 4070's T2a expects the attention part up to ~1.3x faster (no
padding columns, fewer K/V tile loads). The 4070's rule for T2a-2: >= 10 % cold TTFT.

## Plan and gate

Script header: "Rule (declared before the run): exact claim holds if the 4k answers are byte-identical; speed = mean
cold TTFT per depth, t2 vs def. Expected (4070): attention part up to ~1.3x faster. Report TTFT, prefill tok/s and
decode per arm. The build runs first, before any GPU arm, so it does not touch the timings."

## Method

Build first. FLASH_ATTN_EXT op tests with and without the switch. COLD prefill, a fresh server per prompt: def, t2,
def, t2 at 64000, then at 128000. Byte check: one 4k code answer per setting (det_answer.py via run_det.sh).
