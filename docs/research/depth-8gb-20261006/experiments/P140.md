## Question

Does the new engine (0056 + 0057) keep the 8 GB q4_0 default answers identical, and is it no more than 2 % slower at
64k / 128k?

## Why

S05 of the release-20261014b gates (PR #86). 0057 changes the K/V tile dequant for q3 / q4 / q8 and is meant to be
bit-exact for q4_0. The 4070's D28 showed q4 +0.6 %.

## Plan and gate

Script header: "Gate (declared here, before the run): S05 - the answers identical (same sha per item in both rounds;
0057 is meant to be bit-exact for q4_0) and decode at 64k / 128k not more than 2 % slower than bundle-20261014 (means
of 2 rounds); 0 one-token."

## Method

Same session, alternated x2. (a) lookup_ab.py at depth 0 on a fresh server per arm; text hashes compared. (b)
quick_tps 64000 -> 128000, one server per arm.
