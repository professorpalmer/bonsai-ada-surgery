## Question

Which full-attention layers, kept dense (unwindowed) during the prompt read, bring the paraphrased prose set back
toward the full read, and at what cost?

## Why

P174b: window 16k loses 6 prose items. P178 R-4: window 32k gets 9/24. The research shortlist (09:08 CDT, item 2):
"keep 2-4 of the 16 full-attention layers dense if needles drop". The full-attention layers of this model are
3, 7, 11, ..., 63 (every 4th of 64).

## Plan and gate

Script header: "T5 quality knob on the prose set, after the d1cc7a4bd hybrid-input fix; P180 must show dense=15 at 4k =
the plain hash ... Prose set (dense 11/24; T5 16k 5/24; 32k 9/24). Arms: e4: window 16k + dense=15:31:47:63 (4 evenly
spaced full-attention layers); l4: window 16k + dense=51:55:59:63 (the last 4); w32e4: window 32k + dense=15:31:47:63.
Report ok vs dense item by item and the cold time. Stop if P180 C or D differs from P180 B."

## Deviations, incidents, void runs

- Found by this record writer: "Lost in every arm: 7, 9, 22" holds for the three P181 arms, P174b and P182 f4, but P178
  R-4 (window 32k, no dense layers) has item 7 (heron) right.
- Each arm is one run of 24 items. The run-to-run noise of this set is not known yet (P183, running, repeats dense and
  window 32k on prose).
- The cost of 4 dense layers: ~154 s at window 32k (961.9 vs 807.8 s, the same set). At window 16k no prose cold time
  without dense layers exists for the run skip; the n24 document (244,237 tokens) read in 713.1 s (P178 R-1), so 4
  dense layers add about 170 s there (another document of about the same length).

## Verdict

Reported. On the prose set, 4 evenly spaced dense layers lift window 16k from 5 to 9 items (887 s); the last 4 do not
help (5); window 32k + the even 4 gives 10 (962 s). Window 32k with no dense layers (9, 808 s) gives the best quality
per second.
