## Question

During a cold read the 2060 hits its 175 W power cap. Does the 215 W limit (the slider maximum) make cold reads faster,
and how much heat does it add?

## Why

Notebook 05:15 CDT: "during a cold read the card is power-capped (05:10 sample: sw_power_cap active, util 100 %,
144-160 W of a 175 W limit, SM 1,845-1,890 of 2,100 MHz; max limit 215 W)". Earlier tests (P4 / P9, 2026-10-06, an old
engine) measured decode only (+3-5 %, heat-limited at 86 C). Prefill was never tested at 215 W.

## Plan and gate

Script header (declared before the run): "Arms: S1, W1, S2, W2 (each: det_answer 4k + a cold 64k read), then W3 and S3
(a cold 245k-class read each, P170 code set item 1 via p170_drive --only 1, for heat over ~20 min). Gates: identity: the
det 4k hash is equal in every arm; applied: power.limit reads 215 W in W arms and 175 W in S arms (else the arm is void);
speed: mean W 64k prefill beats mean S by more than the S1-S2 spread; heat: max GPU temp < 85 C in every arm; 0 CUDA
errors. The card ends on slot 5 (stock) whatever happens." Profiles switch only with no server running (P39c).

- 240k: 1,418.3 / 1,400.3 = +1.3 %. Power +26-32 W (busy medians, pair by pair), temperature +5-9 C.
- The SM clock median is 1,845-1,875 MHz in both settings. Notebook: "the clock sits on the V-F curve; 215 W removes
  only the cap dips".

## Deviations, incidents, void runs

- The 05:10 sample (sw_power_cap, 144-160 W) is in the notebook only; no receipt holds it.
- Notebook: "card back on slot 5 (175 W confirmed)". run.txt ends with "done (card back on slot 5 by the exit trap)"; it
  has no power.limit reading after the trap. The next job's first stock arm (P202 S1, 07:38:57) read 175 W.
- The install changed slot 1 from memory +500 to 215 W. Slots 3 and 4 (215 W + core +100 / +150) did not change.

## Verdict

PASS on every gate, but the gain is small: +1.8 % at 64k and +1.3 % at 240k for +30 W and +7 C. The power cap is not
the limit; the clock stays on the V-F curve. Not a default and not a serve tip; a core offset is the lever to test
(P202).

## Toolbox (for the next model)

- Data (8 GB, 2060, PTQ1_0 prefill): 215 W in place of 175 W: +1.3-1.8 % prefill, +30 W, +7 C; SM clock unchanged.
- Method: alternate stock and OC arms (S1 W1 S2 W2), gate "applied" on nvidia-smi `power.limit`, then one long read each
  for heat; end on stock with an EXIT trap.
- Pitfall: "power-capped" from one sample does not mean power is the limit; read the SM clock median under both limits.
