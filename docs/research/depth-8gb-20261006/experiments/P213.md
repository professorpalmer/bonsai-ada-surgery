## Question

On the real 8 GB card, is replay rollback (`LLAMA_RS_REPLAY=1`: one recurrent-state plane in place of one per draft
token) byte-identical at a pinned line, how many VRAM cells does it give back, and does a long session stay healthy?

## Why

#201 (merged): "-142 MiB on the 8 GB preset, ~+10k VRAM cells; 4070 decode +10.3 % at 128k"; "default-on waits for R6
on the RTX 2060". #202 staged a replay bundle but did not publish it, because its VRAM-line check (R3) cannot run on the
4070.

## Deviations, incidents, void runs

- First try (69jec6): queued while bin-0070 was still building; it failed 8 s after its start. Notebook 06:13 CDT:
  "first queued too early: it failed at start (receipt deleted by me, cause not kept); it is requeued after the build
  finishes." The rerun's script waits for "0070 exit" in build_ahead.log.
- Found by this record writer: A's 128k request evaluated 95,812 tokens, not ~127k: the server reused the prefix of the
  32k request in the same server (the det filler shares its prefix across depths; P215 restarts the server per depth for
  this reason). A's 128k identity is so a read on a warm prefix. It is still byte-equal off vs on. B ran one depth per
  server (127,340 tokens evaluated).
- Found by this record writer: the soak's turns 4 and 10 read the same token counts as P212 and P211 (3,965 and 3,971)
  and still give P205's form. P211 with the same 18f layer at line 80,128 gives the cache-off form. So at line 90,624
  either the line or replay moves these two near ties; A shows no replay effect at a pinned line, so the line is the
  likely cause. A cache-off run at 90,624 was not made.
- Found by this record writer: the #138 post says the soak walls are "equal to P212 within noise". The restart turns are
  3.1-3.8 s slower (the restore), and turn 2 is 4.0 s slower (the first full save); the other turns are within ~1 s.

## Verdict

PASS. On the 2060, replay rollback is byte-identical at a pinned line, gives back 10,496 VRAM cells at default sizing,
decodes +13.9 % faster at 128k with the same prefill and 12 MiB more headroom, and runs a 12-turn session with restores
and no errors. The formal R6 needs a release zip with 0070.
